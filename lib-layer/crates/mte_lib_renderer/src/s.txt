1) В оперативке всегда хранится реестр, который соотносит id модели с id файла (я решил. что лучше будет просто называть файлы соответствующе id).
2) Потом, будет файл, который соотносит id модели с её названием (это уже чисто для людей), но так то, можно засунуть сюда и id файла с моделью, чтобы этот же файл использовать для загрузки реестра (1).
3) ECS система может сказать о переключении локации. Отрисовщик освобождает память от старых вершин. Менеджер ресурсов отдаёт (возможно, перед этим загружает) новые вершины и всё пихается в буферы ГПУ.
4) Если ECS говорит, что модель надо отрисовать, айди моделей идут в менеджер ресурсов, в котором хранятся метаданные. Оттуда выходят вектора застаканных по материалам примитивов. Это всё идёт на ГПУ, там идёт циклом с попутным переключением конвееров. Ещё данные также будут застаканы по буферам ГПУ. Во время цикла отрисовки буферы тоже будут меняться.
